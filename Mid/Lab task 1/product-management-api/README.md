## Tech Stack
- NestJS
- TypeORM
- PostgreSQL

## Setup Instructions
1. `npm install`
2. Copy `.env.example` to `.env` and fill in your PostgreSQL credentials.
3. Create the database `product_management` in PostgreSQL.
4. `npm run start:dev`

## Endpoints

### Products
- `POST /products`
- `GET /products`
- `GET /products/:id`
- `PATCH /products/:id`
- `DELETE /products/:id`

### Employees
- `POST /employees`
- `GET /employees`
- `GET /employees/:id`
- `PATCH /employees/:id`
- `DELETE /employees/:id`
